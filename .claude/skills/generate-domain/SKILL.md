# Generate Domain

Build a tau2 evaluation domain using the 10-step worldgen pipeline.

**You (Claude Code) are the LLM.** Read each guide, author the artifact, verify it, fix errors, move on. There is no automation — you do the authoring.

## Setup

```python
import sys
sys.path.insert(0, "/Users/eligottlieb/Documents/tau2-bench")
from design.tau2.pipeline import Tau2Pipeline
pipeline = Tau2Pipeline()
```

## The 10 Steps

Work through these IN ORDER. Each step has a guide file to read and a verification call. Do not skip steps.

### Step 1: Concept + Topology
1. Read `design/legacy/guides/01-concept.md`
2. Author `WorldConcept`, `TopologyTargets`, `Tau2Concept` objects
3. Verify: `pipeline.verify_step_1(concept, topology, tau2_concept)`
4. If errors → fix and re-verify. If passed → continue.

### Step 2: Entity Schema
1. Read `design/legacy/guides/02-schema.md`
2. Author `WorldSchema` with `EntitySpec` and `FieldSpec` for each entity from step 1
3. Verify: `pipeline.verify_step_2(schema)`

### Step 3: Relationships + Gates (**critical depth step**)
1. Read `design/legacy/guides/03-gates.md` — this is the most important guide
2. Author `GatedRelationship` list with gate conditions that create depth
3. Verify: `pipeline.verify_step_3(gated_relationships)`
4. If depth target not met → add more sequential gates

### Step 4: Business Rules
1. Read `design/legacy/guides/04-rules.md`
2. Author `Rule` list (mutation guards, protocols)
3. Verify: `pipeline.verify_step_4(rules)`

### Step 5: Seed Data
1. Read `design/legacy/guides/05-seed-data.md`
2. Author `SeedData` with realistic records (8+ per entity)
3. Verify: `pipeline.verify_step_5(seed_data)`

### Step 6: Tools (automatic)
1. Read `design/legacy/guides/06-tools.md` (reference only)
2. Run: `pipeline.step_6_tools()` — derived from schema, no authoring needed

### Step 7: Projections + Sync
1. Read `design/legacy/guides/07-projections-sync.md`
2. Author `SyncSpec` with `SyncBridge` objects
3. Verify: `pipeline.verify_step_7(sync_spec)`

### Step 8: Fault Declarations (**critical composition step**)
1. Read `design/legacy/guides/08-faults.md`
2. Author `FaultSpace` with `FaultGroup` and `FaultDeclaration` objects
3. Verify: `pipeline.verify_step_8(fault_space)`
4. Critical: no two groups share a fix_tool or entity.field

### Step 9: Policy
1. Read `design/legacy/guides/09-policy.md`
2. Author `PolicySpec` with structured rules + prose
3. Verify: `pipeline.verify_step_9(policy)`
4. Use REACTIVE language ("when X is wrong") not PRESCRIPTIVE ("always do X")

### Step 10: Task Generation (automatic)
1. Read `design/legacy/guides/10-tasks.md` (reference only)
2. Run: `result = pipeline.step_10_tasks(seed=42)`
3. Tasks are generated by graph traversal — solvable by construction

## After Step 10

Write the generated tasks to: `data/tau2/domains/{domain_name}/tasks.json`
